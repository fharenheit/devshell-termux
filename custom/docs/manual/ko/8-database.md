# 8. 데이터베이스

[← 설정과 언어](7-settings.md) · [목차](README.md)

PostgreSQL, MySQL/MariaDB, SQLite에 접속해서 SQL을 실행하고 결과를 보고 데이터를 고칩니다. DB 탭은 웹 탭처럼 터미널
자리에 나오고 탭 바에 `🗄 이름`으로 보입니다. 화면 사진은 아직 없습니다. 구현 설명은 [db-client.md](../../db-client.md)에 있습니다.

PostgreSQL과 MySQL/MariaDB는 **Android 8.0 이상**에서 됩니다. SQLite는 모든 기기에서 됩니다.

## 접속 등록

- **+ → 데이터베이스 → DB 접속 관리…**(접속이 없으면 **+ → 데이터베이스…**)에서 **접속 추가**를 누릅니다.
- **종류**를 고르고 호스트, 포트(비우면 기본 포트), 사용자, 비밀번호, 데이터베이스를 넣습니다. SQLite는 파일 경로를 넣습니다(`~/data.db`처럼 `~/`는 홈, 없으면 새로 만듦).
- **비밀번호 저장**을 켜면 SSH 비밀번호처럼 암호화해 저장합니다. 끄면 연결할 때마다 묻습니다.
- **SSL**: 사용 안 함, 인증서 확인 없이 암호화, 인증서 확인 중에서 고릅니다.
- **SSH 터널**: 등록한 SSH 호스트를 거쳐 접속합니다. 이때 위의 호스트와 포트는 SSH 서버에서 본 주소입니다(보통 `127.0.0.1`). `pkg install openssh`가 필요합니다.
- **색상**은 탭 툴바 왼쪽 띠에 나와서 운영 DB를 구분하기 좋습니다. **읽기 전용**을 켜면 데이터를 바꾸는 문장을 실행하지 않습니다.
- **연결 테스트**로 저장하기 전에 접속해 봅니다. 목록에서 접속을 길게 누르면 열기, 편집, 복제, 삭제를 합니다.

## DB 탭

- **+ → 데이터베이스 → 접속 이름**으로 탭을 열면 바로 연결합니다. 탭을 길게 누르면 연결/연결 끊기, 순서 바꾸기, 닫기.
- 툴바: 접속 이름(누르면 연결·편집 메뉴)과 상태, **▶** 실행, **▶▶** 모두 실행, **■** 실행 취소, **⋮** 메뉴.
- 휴대폰에서는 **구조 / SQL / 결과** 버튼으로 화면을 바꾸고, 태블릿이나 가로 화면(폭 720dp 이상)에서는 세 화면이 나란히 나옵니다.
- 뒤로 가기는 SQL 화면으로, 한 번 더 누르면 터미널로 갑니다. 열린 탭과 입력한 SQL은 앱을 다시 열어도 남습니다.

## 구조

- 스키마 → 테이블 → 컬럼을 펼쳐 봅니다. 🔑는 기본 키, ●는 기본 스키마입니다. 위 칸에 글자를 넣으면 테이블을 찾습니다.
- 컬럼을 누르면 SQL 편집기에 이름이 들어갑니다.
- **테이블을 길게 누르기**: 행 보기, 데이터 편집, 행 개수, 컬럼·인덱스·외래 키, DDL 보기, 테이블 전체 내보내기, CSV 가져오기, 이름 넣기/복사

## SQL 실행

- **▶ 또는 Ctrl+Enter**: 커서가 있는 문장(선택한 글이 있으면 그 안의 문장)을 실행합니다. 문장은 `;`로 나눕니다.
- **▶▶ 또는 Ctrl+Shift+Enter**: 모든 문장을 차례로 실행하고 오류가 나면 멈춥니다. 결과마다 위에 탭이 생깁니다.
- `DROP`, `TRUNCATE`, `ALTER`, `WHERE` 없는 `UPDATE`/`DELETE`는 실행하기 전에 확인합니다.
- **자동 완성**: 두 글자를 치면 키워드와 테이블·컬럼 이름이 나옵니다. `o.`처럼 테이블 이름이나 별칭 뒤에 점을 찍으면 그 테이블의 컬럼이 나옵니다. ↑/↓, Enter/Tab, Esc, Ctrl+Space.
- 편집기 위 버튼: 실행 취소/다시 실행, 🕘 실행 기록, ★ 저장한 쿼리, ＋★ 쿼리 저장, EXPLAIN(실행 계획)
- 저장한 쿼리의 `<ID>`처럼 꺾쇠로 감싼 단어는 쓸 때 값을 묻습니다.
- **⋮ 메뉴**: 자동 커밋 켜기/끄기, 한 번에 가져올 행 수, 실행 제한 시간, SQL 정렬, 편집기 비우기

## 결과 표

- 머리글을 누르면 정렬, 머리글 경계를 끌면 너비가 바뀝니다. 행 번호를 누르면 행을 선택합니다.
- 셀을 두 번 누르면 값 전체를 봅니다(JSON은 보기 좋게, 바이너리는 16진수). 길게 누르면 값·행·열 복사, 행 카드, 이 값으로 찾기.
- 위 칸으로 행을 찾고, **⧉**는 복사(표 형식), **⤓**는 CSV/TSV/JSON/Markdown/SQL INSERT로 저장·공유·복사합니다.
- 행이 더 있으면 아래에 **더 가져오기**가 나옵니다.

## 트랜잭션

- 기본은 자동 커밋입니다. **⋮ → 자동 커밋**을 끄면 **✓ 커밋**과 **↶ 롤백** 버튼이 나오고, 바꾼 내용이 있으면 탭 이름 끝에 `*`가 붙습니다.
- 커밋하지 않은 탭을 닫으면 롤백할지 묻습니다.

## 데이터 편집

- 테이블을 길게 누르기 → **데이터 편집**. 기본 키가 있는 테이블만 고칠 수 있습니다.
- 셀을 두 번 누르면 값을 고칩니다(**NULL** 버튼). 행 번호를 길게 누르면 행 삭제, 행 복제. **＋**는 새 행입니다.
- 바뀐 셀은 노란색, 새 행은 초록색, 지울 행은 빨간색으로 보입니다. `WHERE`, `ORDER BY` 칸으로 불러올 행을 정합니다.
- **✓**를 누르면 실행할 `UPDATE`/`INSERT`/`DELETE` 문장을 먼저 보여 주고, 확인하면 한 번에 적용합니다. 그 사이 다른 곳에서 행이 바뀌었으면 아무것도 적용하지 않습니다.

## 내보내기와 가져오기

- **테이블 전체 내보내기**: 백그라운드에서 `Download/테이블.csv` 등으로 저장합니다. 알림에 진행 상황과 취소 버튼이 나오고, 그동안 탭을 계속 쓸 수 있습니다.
- **CSV 가져오기**: `~/data.csv` 같은 홈 디렉터리의 파일이나 클립보드의 글을 넣습니다. 첫 줄이 컬럼 이름이면 이름으로 맞춥니다. 미리 보기를 확인하고 **가져오기**를 누르면 한 번에 넣고, 실패하면 아무것도 넣지 않습니다.

## 저장 위치

- 접속 목록 `~/.termux/db_connections.json`, 저장한 쿼리 `~/.termux/db_queries.json`: 설정 내보내기에 포함됩니다(비밀번호는 제외).
- 실행 기록 `~/.termux/db_history.json`(최근 200개)
